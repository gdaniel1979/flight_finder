# Flight Finder

A Flight Finder egy Python alapú parancssori alkalmazás, amely automatikusan megkeresi az olcsó, egynapos kirándulásra alkalmas Ryanair járatpárokat egy megadott kiindulási repülőtérről. A program a felhasználó által beállított időablakok szerint szűri a járatokat: reggel egy adott óra előtt kell indulni a célállomásra, este pedig egy adott óra után visszaindulni, így biztosítva, hogy a célvárosban értelmes mennyiségű idő álljon rendelkezésre. A keresés több célállomáson és több napon keresztül fut párhuzamosan, és csak azokat az utakat tartja meg, amelyek megfelelnek az árlimitnek és az időbeli feltételeknek. Az eredmények áttekinthető listaként jelennek meg a konzolon, valamint a log fájl tetejére is bekerülnek a későbbi visszakeresés érdekében.

A konfigurációt a `config.yaml` fájlban lehet testre szabni, ahol megadható a kiindulási repülőtér IATA kódja, a reggeli és esti időhatárok, az előretekintési napok száma, a maximális összár, valamint a pénznem. Lehetőség van célállomások explicit megadására vagy kizárására, így a felhasználó könnyen szűkítheti a keresést a számára releváns úti célokra. Az alkalmazás támogatja a Brevo API-n keresztüli email értesítést is, amely automatikusan elküldi a találatokat a megadott címzettnek. A Ryanair scraper alapból engedélyezve van, a Wizzair és easyJet integrációk pedig későbbi fejlesztésre vannak előkészítve. 

A futtatás egyszerű: a `python3.9 main.py` parancs elindítja a teljes keresést a `config.yaml` alapján, míg a `--dry-run` kapcsolóval előre ellenőrizhető, hogy mely célállomások és napok kerülnek lekérdezésre. A projekt moduláris felépítésű, a scraper logika a `scrapers/` könyvtárban, a szűrési logika a `filter.py` modulban, az adatmodellek pedig a `models.py` fájlban találhatók. A naplózás a `logs/` mappába kerül, az új találatok mindig a fájl tetejére kerülnek beszúrásra, így az utolsó futás eredménye azonnal látható megnyitáskor. Az alkalmazás Python 3.9 vagy újabb verziót igényel, és külső függőségként a `pyyaml` valamint a Ryanair API kliens csomagot használja.
